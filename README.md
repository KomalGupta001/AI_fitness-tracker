🚀 Project Setup
Requirements

Node.js (latest version)

Valid API keys (if required)

🖥 Run Locally
1️⃣ Start Backend
cd server
npm install
npm run dev


Ensure required environment variables are configured.
Backend must be running before starting frontend.

2️⃣ Start Frontend
cd client
npm install
npm run dev


Add backend URL in .env file before running.

🌍 Deployment
Backend

Deploy to: https://cloud.strapi.io

Configure environment variables & permissions.

Frontend

Deploy to: https://vercel.com

Update production server URL before deployment.
